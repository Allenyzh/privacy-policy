Privacy Policy for Gemini Summarizer

Last Updated: January 5, 2026

Overview

Gemini Summarizer is a Chrome extension that provides AI-powered webpage summarization using Google's Gemini API. This privacy policy explains what data is collected, how it's used, and your rights regarding your information.

Data Collection and Usage

What Data We Collect

Webpage Content:

  • The extension reads the text content of webpages you choose to summarize
  • This content is extracted only when you actively click the extension icon
  • The content is used solely to generate a summary via the Gemini API

What Data We DO NOT Collect

We do NOT collect, store, or transmit:

  • Personal identity information (name, email, address, etc.)
  • Health information
  • Financial or payment information
  • Authentication credentials (passwords, PINs, etc.)
  • Personal communications
  • Location data
  • Browsing history or tracking data
  • User activity logs

How Your Data is Used

  1. Local Processing:
    • Your API credentials (API URL, API Key, Model name, and custom prompts) are stored locally in your browser using Chrome's storage API
    • These settings never leave your device except when YOU use them to connect to your own Gemini API endpoint
  2. API Communication:
    • When you click to summarize a page, the webpage content is sent to the Gemini API endpoint YOU configured
    • This communication happens directly between your browser and the API endpoint you specified
    • We do not operate any servers or intermediaries that process your data
  3. No Third-Party Sharing:
    • We do not share, sell, or transmit your data to any third parties
    • The only external communication is to the Gemini API endpoint that YOU provide and control

Data Storage

  • Local Storage Only: All configuration settings (API URL, API Key, Model, and Prompts) are stored locally in your browser using Chrome's sync storage
  • No Cloud Storage: We do not maintain any servers or cloud storage for user data
  • No Analytics: We do not use analytics, tracking, or telemetry services

Your API Credentials

You are required to provide your own:

  • Gemini API URL
  • API Key
  • Model name

These credentials are:

  • Stored securely in your browser's local storage
  • Never transmitted to us or any third party
  • Used exclusively to communicate with the Gemini API endpoint you specify
  • Your responsibility to manage and protect

Data Security

  • All data is stored locally using Chrome's built-in storage API
  • Communication with the Gemini API uses HTTPS encryption
  • We recommend keeping your API keys secure and not sharing them with others

Third-Party Services

This extension uses the marked.js library (included locally) to render Markdown-formatted summaries. This library runs entirely within your browser and does not transmit any data externally.

The extension communicates with Google's Gemini API based on the endpoint YOU configure. Please refer to Google's Privacy Policy for information about how Google handles data sent to their API.

User Rights

You have the right to:

  • Access your stored settings at any time through the extension's settings panel
  • Modify or delete your API credentials at any time
  • Uninstall the extension, which will remove all locally stored data

Children's Privacy

This extension is not directed at children under the age of 13. We do not knowingly collect information from children.
